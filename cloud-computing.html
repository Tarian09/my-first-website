Introduction to Cloud Computing

This page contains my notes for the CC6004NU Network and Cloud Security module.

1. Definition of Cloud Computing

Cloud computing is the delivery of computing services over the internet. These services include servers, storage, databases, networking and software. Organisations can access resources when needed without having to own and maintain all the physical infrastructure.

2. Essential Characteristics

  • On-demand self-service
  • Broad network access
  • Resource pooling
  • Rapid elasticity
  • Measured service

3. Cloud Service Models

Infrastructure as a Service (IaaS)

Provides computing resources such as virtual machines, storage and networking. Customers manage their operating systems and applications.

Platform as a Service (PaaS)

Provides a managed platform for developing and running applications without managing all the underlying infrastructure.

Software as a Service (SaaS)

Provides ready-to-use software over the internet, usually through a web browser.

4. Cloud Deployment Models

  • Public cloud: Services are provided over the internet by a cloud provider.
  • Private cloud: The cloud environment is dedicated to one organisation.
  • Community cloud: Infrastructure is shared by organisations with common requirements.
  • Hybrid cloud: Two or more distinct cloud environments are connected to support data or application portability.

5. Cloud Security

Cloud security involves protecting data, applications and infrastructure from unauthorised access and cyberattacks. Important controls include identity management, access control, encryption, monitoring and regular backups.

6. Cloud Computing Reference Architecture

The NIST Cloud Computing Reference Architecture identifies five main actors: the cloud consumer, cloud provider, cloud broker, cloud auditor and cloud carrier.

7. Cloud Providers

Examples of cloud providers include Microsoft Azure, Amazon Web Services, Oracle Cloud, IBM Cloud, Google Cloud and Alibaba Cloud.

These providers offer different services and deployment options. Organisations should compare security, cost, compliance and technical requirements when choosing a provider.
